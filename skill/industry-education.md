# 教育行业专项检查（dsh-industry-education）

**什么时候用**：教育类 App / 小程序 / 家校通 / 校园应用上线前，或做行业合规自查时。
想知道「教育移动应用备案号公示了吗」「有没有备案信息表」「代码里有没有公开成绩排名」
「依赖里有没有广告或游戏 SDK」「适龄范围写了吗」「学籍号有没有明文落库」
「儿童个人信息保护负责人指定了吗」。

用户会说：「教育 App 要查什么」「我们小程序备案号放哪」「成绩排行榜能不能做」
「学籍号能存库里吗」「儿童个人信息保护负责人怎么配」「家校通上线前帮我扫一遍」。

## 怎么用

```bash
<cli 路径> --root <项目目录>       # 检查一个项目
<cli 路径> --demo                  # 用内置样本看检出效果（7 条全部触发）
<cli 路径> --list-rules            # 列出 7 条判据与出处
<cli 路径> --json                  # JSON，给 CI 二次处理
<cli 路径> --html edu.html         # 出 HTML 报告（可截图存档）
<cli 路径> --quiet                 # 只输出结论行
```

退出码：有 high 命中 → 1（可挂 CI 卡口），否则 0。

## 它查什么

7 条判据，每条都指得到官方条款：

| 规则 | 查什么 |
|---|---|
| `EDU-APP-FILING-PUBLIC` | 关于页 / i18n / 前端资源 / app.json / Info.plist 里找不到 `教APP备NNNNNNN号` 形式的备案号 |
| `EDU-APP-FILING-RECORD` | 找不到教育移动应用备案信息表（`docs/compliance/教育移动应用备案信息.md`、`edu-app-record.*` 等） |
| `EDU-SCORE-RANK-PUBLIC` | 代码或前端资源里出现成绩排名、名次榜单、`/score/rank`、高考喜报 / 升学率 |
| `EDU-AD-GAME-SDK` | 依赖清单里出现 AdMob / play-services-ads / 广点通 / mobads / BUAdSDK / Unity / Cocos2d |
| `EDU-AGE-RANGE-NOTICE` | 面向未成年人，但 app.json / Manifest / Info.plist / 关于页都没有适龄 / ageRating |
| `EDU-STUDENT-ID-EXPOSURE` | 文件里出现 `G`/`L` + 18 位 的学籍号格式（整文件匹配） |
| `EDU-CHILD-PI-OFFICER` | 文档/配置里找不到「儿童个人信息保护负责人」+ 联系方式（或 `child_pi_officer` / `dpo_contact`） |

### 什么时候不适用（`when`）

- 第 1、2 条只在**有移动端入口**时跑（Info.plist / AndroidManifest / react-native / expo / uni-app 等）—— 纯后端不误报
- 第 3、4、6 条只在**教育行业信号**出现时跑（教育 / 学生 / 学籍 / 校园 / 家长 / 教师 / 班级 / 课程等）
- 第 5 条只在出现「中小学生 / 小学 / 初中 / 高中 / 幼儿园 / 未成年」时跑 —— 高校 / 职教 / 成人培训不适用
- 第 7 条只在出现「儿童 / 未成年人 / 中小学生 / 幼儿园 / 青少年 / 14周岁」时跑

不适用的规则会进 `notApplicable`，既不报也不假装查过。

## 怎么读结果

1. **先看扫描范围和「跑了 N/7 条规则」**。N 小于 7 说明有规则因 `when` 不适用没跑，
   报告里会点名 —— **这不是全绿**。
2. **命中 ≠ 违规**，它是提示你去确认：
   - `EDU-SCORE-RANK-PUBLIC`：`rank` 可能只是数组排序变量，先看上下文
   - `EDU-AD-GAME-SDK`：**仅命中依赖名不判违规** —— 可能是历史遗留或间接依赖，
     确认它是否真的会向学生展示广告或提供游戏
   - `EDU-STUDENT-ID-EXPOSURE`：**这是格式命中** —— 确认是真实学籍号还是占位数据；
     真实号码请从代码库移除并改成脱敏值
   - `EDU-APP-FILING-RECORD`：备案信息表可能在内部知识库，不在仓库里
3. **absence 类规则整组只报一次**（第 1、5、7 条），不会重复刷屏。

## 它不查什么

- ❌ 不判断**事实**：后台是否真的返回了学籍号、App 是否真的展示了榜单，它查不到
- ❌ 不处理**否定句**：文档里写「本项目不面向未成年人」也会被当成未成年人信号
- ❌ 不查**监护人同意 / 儿童个人信息处理规则 / 青少年模式** —— 那是 `dsh-minor-guard` 的活
- ❌ 不查**工信部 ICP / APP 备案** —— 那是 `dsh-cn-filing` 的活（本插件查教育移动应用备案）
- ❌ 不下**「合规 / 不合规」结论**，不承诺「保证通过检查」
- ❌ 不替你**补材料**：备案信息表、适龄说明、负责人信息都要你自己写

## 相关插件

- `dsh-cn-filing` —— 工信部 ICP / APP 备案公示
- `dsh-minor-guard` —— 监护人同意、儿童个人信息处理规则、青少年模式
- `dsh-pipia` —— 个人信息保护影响评估与处理记录
- `dsh-data-scan` —— 更广的敏感数据扫描（身份证 / 银行卡 / 手机号等）
- `dsh-consent-guard` —— 用户同意与隐私授权流程
